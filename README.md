# CoC7thdice

React 写的花里胡哨随机数生成器，使用了 Ant Design 的组件，可以生成一些人物属性和随机骰子用来跑团，请前往移动端界面获得最佳体验。

------

A simple ReactJS page that can generate random numbers for COC-TRPG, switch to the mobile interface for the best experience.
